# Scripts geradores — VoltEx Comercial

Ordem: `python build_model.py <saida>/VoltEx.Comercial.SemanticModel` → `python build_report.py <saida> <pasta VoltEx.Distribuidora.Report>`.
O relatório reaproveita report.json, tema, fundos e logo salvos pelo Desktop no projeto Distribuidora (só leitura).
Depois de aberto e salvo no Power BI Desktop, a fonte de verdade passa a ser a pasta `.pbip`, não estes scripts.
